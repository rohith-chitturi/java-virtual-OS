# Java Virtual OS

A comprehensive, modular, event-driven operating system simulator written entirely in Java. This project models the core subsystems of a modern OS—process scheduling, memory management, virtual file systems, inter-process communication, networking, and device management—providing an interactive shell to explore and visualize these concepts.

## Features

- **Process Management**: Simulated process blocks (PCBs), parent-child relationships, and configurable CPU schedulers.
- **Memory Management**: Physical memory tracking alongside a simulated MMU for page faults and virtual memory mapping.
- **Virtual File System (VFS)**: A unified Unix-like hierarchical file system, complete with file descriptors and dynamic mounting.
- **Security & IPC**: User/Group abstractions, permissions, and internal signaling for inter-process communication.
- **Networking**: A simulated TCP/IP stack with a local routing table and socket simulation without binding host network ports.
- **Device Management**: A hardware abstraction layer managing device drivers (e.g., `/dev/null`, `/dev/zero`, `/dev/random`) natively within the VFS.

## Architecture

The project is structured into fully decoupled subsystems communicating via a central `KernelEventBus`. See [docs/architecture.md](docs/architecture.md) for detailed Mermaid diagrams and subsystem interactions.

Key subsystems include:
- `com.rohith.javavirtualos.kernel.process`
- `com.rohith.javavirtualos.kernel.memory`
- `com.rohith.javavirtualos.filesystem`
- `com.rohith.javavirtualos.kernel.network`
- `com.rohith.javavirtualos.kernel.device`

## Getting Started

### Requirements
- Java 17+
- Maven 3.8+

### Building
```bash
mvn clean package
```

### Running the Simulator
```bash
mvn exec:java -Dexec.mainClass="com.rohith.javavirtualos.JavaVirtualOS"
```

## Demo Commands

Once the shell starts (`JavaOS> `), try these commands to explore the OS internals:

- `help`: Lists all available commands.
- `lsdev` or `devices`: Displays all registered device drivers and their capabilities.
- `devstat`: Shows global I/O statistics across all devices.
- `cat /dev/random`: Streams random bytes generated by the virtual random device.
- `ps` and `pstree`: Views the currently running virtual processes.
- `netstat`: Displays active virtual network sockets and routing tables.
- `ping 127.0.0.1`: Pings the internal loopback interface using the simulated network stack.

## Testing

The simulator relies heavily on deterministic JUnit 5 testing to ensure subsystem stability. Run the full test suite with:

```bash
mvn clean test
```
